# STS2-Solver

《Slay the Spire 2》單人／雙人戰術工作台。獨立的 Windows 讀取器將遊戲記憶體快照交給本機網頁，再由網頁計算這一回合的推薦出牌。

## 執行

在專案目錄以 PowerShell 執行，需有 Windows x64 .NET 6 SDK，並啟動 Steam 版遊戲。

```powershell
dotnet run --project reader
```

1. 開啟 [本機戰術工作台](http://127.0.0.1:8765/)。
2. 在遊戲進入可出牌的回合，按「讀取目前戰鬥」。
3. 核對牌面。可按「套用基礎牌面值」快速填入讀到的提示，再依遊戲預覽修正實際費用、每擊傷害、擊數、格擋與敵方攻擊。畫面已知沒有攻擊意圖的敵人會預填 0。無法用目前模型描述的牌可標為「不納入搜尋」。
4. 讀取推薦後在遊戲中出牌。局面改變時重新擷取。

讀取器只支援本機驗證的 v0.113.1 遊戲組件。頁面也可直接開啟 `index.html` 手動輸入。雙人每位各最多 10 張手牌，共享最多 3 名敵人。讀取器會嘗試從同一個遊戲客戶端取得雙方手牌，雙人實機完整性仍待驗證。

## 模型與研究

目前評估一個回合內的直接傷害與格擋。達到節點數或時間上限時，頁面會標示最佳候選只來自已搜尋的範圍。未模擬抽牌、藥水、狀態連鎖與後續回合，因此尚無完整 Boss 戰的勝率或最佳解保證。
